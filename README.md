# Sistema de Denúncia de Infraestrutura Urbana

## Sobre o projeto

Este projeto consiste em uma página web desenvolvida para registrar denúncias relacionadas a problemas de infraestrutura urbana. O sistema permite que cidadãos informem ocorrências de maneira organizada, rápida e simples.

A proposta do projeto é centralizar informações sobre problemas urbanos, facilitando o envio de denúncias e auxiliando no acompanhamento de possíveis soluções.

---

# Funcionalidades

* Cadastro de dados do denunciante
* Registro do local do problema
* Seleção do tipo de problema
* Definição do nível de urgência
* Seleção de riscos associados
* Campo de descrição detalhada
* Botões para envio e limpeza do formulário
* Layout responsivo para dispositivos móveis
